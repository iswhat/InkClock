📱 InkClock 设备配网指南

ESP32 墨水屏设备的配网与访问方式

🔄 配网流程

1

设备上电，进入配网模式

首次上电后，ESP32 会自动创建一个 WiFi 热点，热点名称为 InkClock_XXXX（XXXX 是设备 MAC 地址后四位）。

2

连接设备热点

在手机或电脑的 WiFi 设置中，搜索并连接 InkClock_XXXX 热点。连接密码默认为：12345678

3

访问配网页面

打开浏览器，访问 192.168.4.1 或 192.168.4.1/wifi_config

⚠️ 重要：WiFi 配置页面无需登录，可直接访问进行配网！
4

输入 WiFi 信息

在页面中输入您要连接的 WiFi 名称（SSID）和密码，然后点击保存。设备会自动重启并连接到您的 WiFi 网络。

5

通过局域网访问设备

设备连接 WiFi 后，可通过以下方式访问：

  • 通过 IP 地址：http://192.168.x.x
  • 通过局域网域名：http://inkclock.local
  • 通过路由器查看设备 IP

🌐 访问方式对比

场景 访问地址 是否需要登录 用途
首次配网（AP 模式） 192.168.4.1 无需登录 配置 WiFi 连接
WiFi 配置页面 /wifi_config 无需登录 修改 WiFi 设置
设备主页 / 需要登录 查看设备状态
系统设置 /settings 需要登录 配置设备参数
插件管理 /plugins 需要登录 管理插件
💡 说明：
  • 配网页面（/wifi_config）无需任何认证，这是设计如此，方便首次配网
  • 其他页面需要输入用户名和密码登录
  • 默认登录凭据：用户名 admin，密码 admin
  • 登录会话有效期为 30 分钟
