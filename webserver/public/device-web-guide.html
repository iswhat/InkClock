🌐 InkClock 设备内置 Web 服务器

ESP32 墨水屏设备内置的完整 Web 管理系统

📡 连接方式

设备内置 Web 服务器支持多种连接方式，满足不同场景需求：

📶
WiFi 热点
设备创建 AP 热点，手机/电脑直接连接访问
热点名称: InkClock_XXXX
访问地址: 192.168.4.1
无需外部网络
🏠
局域网访问
设备连接家庭 WiFi 后，通过局域网访问
访问地址: http://[设备 IP]
或: http://inkclock.local
推荐方式
📱
蓝牙连接
通过蓝牙连接设备，使用手机 App 访问
蓝牙名称: InkClock_BT
支持: 蓝牙 4.0+
近距离管理
⚡
星闪连接
新一代短距通信技术
更低延迟: 1/30 蓝牙延迟
更高速率: 6 倍蓝牙速率
新技术
📷
扫码访问
设备屏幕显示二维码，手机扫码直接访问
包含: 设备 IP 和访问端口
快捷: 无需手动输入地址
最便捷
💡 连接方式说明：
  • 首次配网：使用 WiFi 热点方式，设备创建热点，手机连接后访问 192.168.4.1
  • 日常使用：设备连接家庭 WiFi 后，通过局域网访问（推荐）
  • 近距离管理：可使用蓝牙或星闪连接，通过手机 App 管理
  • 快速访问：设备屏幕显示二维码，手机扫码直接打开管理页面

🔐 认证说明

页面类型 示例 认证要求 说明
配网页面 /wifi_config 无需认证 首次配网使用，无需密码
登录页面 /login 无需认证 提供登录入口
设备主页 / 需要登录 查看设备状态和信息

功能管理 /plugins, /fonts, etc. 需要登录 管理插件、字体等功能
🔑 登录凭据：
  • 默认用户名：admin
  • 默认密码：admin
  • 会话有效期：30 分钟
  • 超时后需重新登录

🏠 与独立 Web 服务器的区别

📱 设备内置 Web

  • 运行在 ESP32 设备上
  • 无需外部服务器
  • 支持多种连接方式（WiFi/蓝牙/星闪）
  • 本地直接管理设备
  • 适合个人使用和调试
  • 功能：配网 + 设备管理
  • 认证：简单 Session（30 分钟）

🌐 独立 Web 服务器

  • 运行在 PC/服务器上
  • 需要独立部署
  • 通过网络连接设备
  • 集中管理多个设备
  • 适合多用户场景
  • 功能：设备管理 + 消息推送 + OTA
  • 认证：完整用户系统
💡 使用建议：
  • 个人使用：直接用设备内置 Web 就够了，扫码或局域网访问都很方便
  • 多设备管理：使用独立 Web 服务器，可以统一管理多个设备
  • 开发调试：设备内置 Web 更直接，修改代码后立即可用
  • 消息推送：需要独立 Web 服务器，支持向设备推送消息

📋 快速开始

首次使用流程

  1. 设备上电 - 等待设备启动完成
  2. 连接热点 - 手机连接 InkClock_XXXX 热点
  3. 访问配网 - 浏览器打开 192.168.4.1（无需密码）
  4. 配置 WiFi - 输入家庭 WiFi 信息并保存
  5. 等待重启 - 设备重启并连接 WiFi
  6. 扫码访问 - 设备屏幕显示二维码，扫码打开管理页面
  7. 登录管理 - 使用 admin/admin 登录，开始配置设备
打开独立 Web 服务器 返回预览页
